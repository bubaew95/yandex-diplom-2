# Руководство по использованию диалогов в TUI

Этот документ описывает работу с модальными окнами (диалогами) в TUI-приложении, реализованными с помощью библиотеки [tview](https://github.com/rivo/tview).

## Структура `Dialog`

```go
// Dialog описывает параметры модального окна.
type Dialog struct {
    Title       string      // Заголовок окна
    Message     string      // Сообщение (основной текст)
    BtnNegative string      // Название кнопки "Отмена"
    BtnPositive string      // Название кнопки "ОК" или подтверждения
    Positive    func()      // Коллбэк при нажатии кнопки "ОК"
    Negative    func()      // Коллбэк при нажатии кнопки "Отмена"
}
```

## Функции отображения

### `showDialog(d Dialog)`

Вызывает отображение модального окна с кнопками и сообщением, заданными в `Dialog`.

**Пример:**

```go
t.showDialog(Dialog{
    Title:       "Удаление",
    Message:     "Вы уверены, что хотите удалить элемент?",
    BtnPositive: "Да",
    BtnNegative: "Нет",
    Positive: func() {
        // Логика удаления
    },
    Negative: func() {
        // Отмена действия
    },
})
```

### `showError(message string)`

Упрощённый вариант `showDialog` для вывода ошибок. Кнопка одна — "OK".

**Пример:**

```go
t.showError("Не удалось загрузить файл")
```

### `showInfo(message string)`

Отображает информационное сообщение. Кнопка одна — "OK".

**Пример:**

```go
t.showInfo("Данные успешно сохранены")
```

## Диалоги выбора файлов и директорий

### `showFileDialog(callback func(string))`

Открывает диалог выбора **файла**. После выбора путь передаётся в callback.

**Пример:**

```go
t.showFileDialog(func(path string) {
    fmt.Println("Выбран файл:", path)
})
```

### `showFileDialogForDir(callback func(string))`

Открывает диалог выбора **директории** с возможностью её создания.

**Пример:**

```go
t.showFileDialogForDir(func(path string) {
    fmt.Println("Выбрана директория:", path)
})
```

## Пользовательские формы

### `createDialogForm(...)`

Создаёт диалог с полем ввода и настраиваемыми кнопками. Возвращает форму и поле ввода. Используется в составе `showDirDialog`.

## Вспомогательные функции

### `getInitialDirectory()`

Возвращает стартовую директорию для файлового диалога:

- сначала `t.Data.lastFileDialogDir` (если задано);
- затем домашний каталог пользователя;
- в крайнем случае — текущую рабочую директорию.

---

Если необходимо расширить поведение диалогов — добавьте в `Dialog` новые поля (например, флаги для отмены закрытия окна или иконки).
